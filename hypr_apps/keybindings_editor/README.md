# Hyprland Keybindings Editor

The **Hyprland Keybindings Editor** is a GTK4/Libadwaita application written in Rust for managing Hyprland keybindings. It serves as both a standalone application and a module for the overarching Preferences Application.

## Build and Run

To build the application in release mode:

```bash
cargo build --release
```

To run the application for development and testing:

```bash
cargo run
```

## Install

To install the application onto your system via `cargo`:

```bash
cargo install --path .
```
