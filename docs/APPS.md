# Applications and Tools Documentation

This document outlines the key applications and tools integrated into this Hyprland environment.

## Core Applications

### Waybar (`~/.config/waybar/`)

The status bar. It displays information like workspaces, date/time, hardware status (CPU, RAM), and media controls.

* **Config**: `config.jsonc` defines the modules and their layout.
* **Style**: `style.css` handles the visual appearance. It is dynamically updated by the theme generator to import the current theme's CSS (`theme.css`) and the default modules CSS (`modules.css`).
* **Custom Modules**: Uses scripts like `bin/arch-update` and `bin/hypr-weather` to provide dynamic data.

### Walker (`~/.config/walker/`)

The application launcher, clipboard manager, and extensible menu system.

* **Config**: `config.toml` contains general settings.
* **Elephant**: `elephant.toml` configures the service component for clipboard history and background tasks.
* **Modules**: Walker supports various built-in modules like clipboard, symbols, and snippets (`walker -m snippets`).
* **Theming**: Dynamic theming is handled by `hypr-theme-templater` which uses a Jinja2 template. It combines a base CSS file with the theme's specific `walker.css` to generate the final style configuration.

### Terminal Emulators

* **Kitty** (`~/.config/kitty/`): The primary terminal. Its configuration is split between a base `kitty.conf` and a theme-specific `theme.conf` which is generated by the theme engine.
* **Alacritty** (`~/.config/alacritty/`): An alternative terminal. Theming is applied by updating `alacritty.toml`.

### Neovim (`~/.config/nvim/`)

The text editor.

* **LazyVim**: The configuration is based on LazyVim.
* **Theme Integration**: A `theme.lua` file in `lua/plugins/` is generated from the active theme's `neovim.theme.lua` file, ensuring the editor matches the system theme.

### Hyprlock (`~/.config/hypr/hyprlock.conf`)

The screen locker.

* It uses variables like `$background_color` and `$accent_color` which are populated from the theme configuration.

### Hypridle (`~/.config/hypr/hypridle.conf`)

Idle management daemon.

* Manages screen dimming and locking after periods of inactivity.


### Preferences App (`hypr-preferences-app`)

The central hub for managing your Hyprland environment's settings.

* **Features**:
  * **Theme Management**: Switch between system and user themes, and change system fonts.
  * **Appearance Customization**: Interactively adjust gaps, borders, rounding, shadows, and blur effects.
  * **System Tools**: Access system maintenance scripts and logs.
  * **Wallpaper Browser**: Visually browse and apply wallpapers from your themes or personal collection.

### Keybindings Editor (`hypr-keybindings-editor`)

A graphical application built with GTK4 and Libadwaita for managing and editing Hyprland keybindings.

* **Key Features**:
  * **Interactive Key Capture**: Allows users to set keybindings by pressing key combinations directly, eliminating manual entry.
  * **Conflict Detection**: Automatically checks for conflicts with existing Hyprland keybindings and common system-wide shortcuts (e.g., Copy/Paste, Alt+Tab) to prevent accidental overwrites.
  * **Floating Window**: Configured to launch as a floating window for convenient access and interaction.

### SwayOSD (`~/.config/swayosd/`)

A GTK-based On-Screen Display (OSD) for volume and brightness.

* **Style**: `style.css` is generated by the theme engine, inheriting the unified font family and rounding from the current theme.
* **Functionality**: Triggered by scripts like `bin/hypr-restart-swayosd` and integration with hardware keys.

### Swappy (`~/.config/swappy/`)

A snapshot editing tool.

* **Config**: `config` file is templated to ensure consistent font usage for text annotations, using `theme.fonts.font_family`.
* **Integration**: Used by the screenshot scripts for quick editing after capturing a screen region.

## Other Tools

* **Mako**: Notification daemon. Styled via `mako.ini` in the theme directory. Its appearance (colors, borders, rounding, and font size) is dynamically managed by the theme engine.
* **Starship**: Shell prompt, configured in `config/starship.toml`.
* **Btop**: System monitor, themed via `btop.theme`.
* **Fastfetch**: System information fetcher.
  * **Config**: `config/fastfetch/config.jsonc` defines the structure and modules displayed (OS, kernel, uptime, packages, etc.).
