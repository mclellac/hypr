# hypr_config_manager

This library is the core configuration engine for the `hypr` desktop environment.

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
hypr_config_manager = { path = "../hypr_config_manager" }
```

## Build

```bash
cargo build --release
```

## Install

This is a library and is not meant to be installed globally on its own.
